# 工程分类案例库（category_cases.md）

## 本文件的定位

本文件是**工程分类案例库**，用于让模型学习"某种类型的工程，分类目录通常大概长什么样"。

**案例不是固定分类白名单。**

- 案例只提供：分类颗粒度、合并方式、拆分方式、命名风格、工程功能关系的参考；
- 最终分类必须由**当前工程的实际物料**决定；
- 分类判断流程与护栏见 `SKILL.md`「动态分类方法论」章节。

## 案例结构约定

每个案例尽量包含：

1. 工程类型特征
2. 参考分类形态（小/中/大型项目粒度变化）
3. 为什么这样合并
4. 为什么这样拆分
5. 命名特点
6. 常见错误
7. 后续新案例优先整理进本文件，而不是往 SKILL.md 加固定关键词规则

## 案例 1：选煤厂/矿井（横沟）

### 1. 工程类型特征

- 选煤厂或矿井项目，专业构成：洗选工艺、供配电、自动化（PLC）、网络通信、安防、暖通除尘、软件平台。
- 智能化程度高的选煤厂，自动化、网络、安防类设备占比大。

### 2. 参考分类形态

| 分类名 | 装什么 |
| --- | --- |
| PLC 模块 + 仪表传感器 | PLC 模块、I/O 模块、仪表、传感器、变送器、电控阀 |
| 光纤网线类 | 光纤、光缆、网线、跳线、光纤收发器 |
| 安防车辆管控 | 摄像机、门禁、道闸、车牌识别、人员定位 |
| 工控服务器 UPS | 工控机、服务器、操作工作站、UPS、存储 |
| 显示大屏看板 | LED 屏、看板、显示器 |
| 机柜箱体配电 | 机柜、控制柜、配电箱、采集箱、I/O 机架 |
| 线缆管材类 | 电缆、钢管、桥架、母线、接地 |
| 网络交换设备 | 交换机、网关、防火墙 |
| 安装辅材杂项 | 支架、扎带、密封罩、通用安装附件 |
| 软件定制服务 | 软件、平台、组态、数据中台 |
| 未分类项目 | 无法可靠归类的兜底 |

粒度变化：

- 小型项目（如单独一个车间改造）：PLC 与仪表可合并、网络设备少时「网络交换设备」与「光纤网线类」可合并，机柜箱体与配电可合并，最终 5~7 类；
- 中型项目：按上表 10 类左右；
- 大型项目：PLC 与仪表可拆分（如「PLC 模块」「仪表传感器」），线缆管材可拆「电缆类」「桥架管材类」。

### 3. 为什么这样合并

- 光纤/网线/跳线同属传输介质，采购渠道相同 → 合并「光纤网线类」；
- 电缆/钢管/桥架/母线同属敷设材料，施工界面相同 → 合并「线缆管材类」；
- PLC 与仪表传感器在控制回路中配套工作 → 合并；
- 摄像机/门禁/道闸同属安防子系统 → 合并。

### 4. 为什么这样拆分

- 工控机/服务器/UPS 是计算存储与电源保障设备，与网络交换设备职责不同 → 拆开；
- 交换机/网关是网络核心，与光纤网线（传输介质）拆分；
- 大屏看板是信息展示，与监控摄像机拆分。

### 5. 命名特点

- 材料类用「XX类」（光纤网线类、线缆管材类）；
- 设备类用「设备类型 + 及 + 设备类型」（PLC 模块 + 仪表传感器、工控服务器 UPS）；
- 命名让负责人一眼看出装什么。

### 6. 常见错误

- 把路灯、轴流风机、空调塞进「工控服务器 UPS」（错误：功能完全不匹配）；
- 把高压开关柜、变压器塞进「机柜箱体配电」（错误：机柜箱体配电只放机柜/箱体/机架/模块）；
- 把安装工序行（电缆敷设、立杆安装）当作设备收进清单；
- 配电箱与配电柜混淆（配电箱是箱体类，配电柜是配电设备本体）。

### 7. 配套格式参考

横沟模板的 Excel 格式、列名改写、续写行、产品说明规律见 `references/henggou_template_pattern.md`（那是格式参考，不是分类白名单）。

## 案例 2：供配电工程（榆树湾）

### 1. 工程类型特征

- 供配电系统专业项目（如选煤厂供电系统章节），专业构成以高低压配电、保护自动化、防爆现场电器、照明、暖通、电缆敷设为主。

### 2. 参考分类形态

| 分类名 | 装什么 |
| --- | --- |
| 高低压配电柜及变压设备 | 高压开关柜、干式变压器、低压进线/联络/馈出柜、电容补偿柜、滤波柜、软启动器柜、变频器柜 |
| 保护自动化及直流设备 | 综合自动化保护装置、直流屏、自动化后台 |
| 防爆控制箱及现场电器 | 防爆风机箱、防爆检修电源箱、防爆刀开关、液位计、浮球开关、按钮盒 |
| 配电室暖通设备 | 轴流风机、电暖风机、空调 |
| 照明及现场开关设备 | 路灯、路灯控制箱、负荷开关 |
| 电缆桥架及接地材料 | 高压/低压电缆、桥架、封闭母线桥、接地线 |
| 未分类项目 | 兜底 |

粒度变化：

- 小型：照明与防爆现场电器可合并、暖通设备少时并入未分类或单独小类；
- 大型：电缆与桥架可拆「电缆类」「桥架及接地材料」。

### 3. 为什么这样合并

- 开关柜/变压器/补偿柜/变频器都是配电设备本体 → 合并；
- 电缆/桥架/母线/接地同属输配电材料 → 合并；
- 防爆箱体与现场控制电器布置在同一爆炸危险区域 → 合并。

### 4. 为什么这样拆分

- 保护自动化与直流系统是二次设备，与一次配电设备拆分；
- 暖通设备（风机/空调）保障配电室环境，不是配电本体 → 单独成类；
- 照明（路灯）与配电设备拆分。

### 5. 命名特点

- 设备类用「XX及XX设备」，材料类用「XX及XX材料」；
- 命名直接反映设备类型与功能。

### 6. 常见错误

- 把高压开关柜、变压器塞进「机柜箱体配电」（机柜/箱体/机架/模块类名无法解释配电设备本体，应归入供配电相关分类；具体分类名由当前工程物料决定）；
- 把路灯塞进「工控服务器 UPS」（不匹配）；
- 安装工序行（电缆敷设、照明灯具安装）误收为设备。

### 7. 参考项目

榆树湾供电系统采购清单及产品说明（6 类清晰分类）。

## 案例 3：智能化/弱电工程

### 1. 工程类型特征

- 智能化/弱电工程，设备构成：PLC、I/O 模块、仪表、传感器、光纤、网线、摄像机、道闸、车牌识别、工控机、服务器、UPS、大屏、机柜、配电箱、电缆、线管、交换机、安装辅材。
- 专业构成相对单一，但子系统多（自动化、网络、安防、显示、机房）。

### 2. 参考分类形态

与横沟案例高度相似（同为智能化程度高的项目）：

| 分类名 | 装什么 |
| --- | --- |
| PLC 模块 + 仪表传感器 | PLC、I/O、仪表、传感器 |
| 光纤网线类 | 光纤、网线、跳线 |
| 安防车辆管控 | 摄像机、道闸、车牌识别 |
| 工控服务器 UPS | 工控机、服务器、UPS |
| 显示大屏看板 | 大屏、看板 |
| 机柜箱体配电 | 机柜、配电箱、控制柜 |
| 线缆管材类 | 电缆、线管、桥架 |
| 网络交换设备 | 交换机、网关 |
| 安装辅材杂项 | 支架、扎带、通用附件 |
| 未分类项目 | 兜底 |

粒度变化（动态，不固定）：

- 工程 A 网络设备较少 → 只需「网络通信类」一个类；
- 工程 B 网络设备很多 → 拆「网络交换设备」「光纤网线类」「光模块及光纤配件」。

### 3. 为什么这样合并

- 摄像机支架跟随安防主体；
- PLC 扩展模块跟随 PLC/自动化；
- 交换机专用电源跟随网络交换设备；
- 大屏发送卡跟随显示大屏（附件跟随主体原则）。

### 4. 为什么这样拆分

- 网络设备多时按设备类型拆分；
- 各子系统规模都大时按子系统拆分。

### 5. 命名特点

同横沟案例。

### 6. 常见错误

- 生成「电子设备类」「综合设备类」「电气设备类」「其他材料类」这类**明显过粗、信息量低**的分类，偏离成熟案例形态 → 应重新检查；
- 仅凭"交换""柜"等关键词分类，不结合工程功能。

### 7. 配套格式参考

横沟模板格式规律见 `references/henggou_template_pattern.md`。

## 案例 4：暖通/动力工程

### 1. 工程类型特征

- 暖通/动力专业，设备构成：锅炉/热源、空调机组、通风风机、除尘抑尘装置、水泵、风管水管附件。

### 2. 参考分类形态

| 分类名 | 装什么 |
| --- | --- |
| 供暖设备 | 锅炉、换热器、供暖循环泵、供暖分区设备 |
| 空调设备 | 空调机组、精密空调、空调柜机 |
| 通风风机设备 | 轴流风机、屋顶风机、防腐防爆风机 |
| 除尘抑尘设备 | 干雾抑尘系统、惯性降尘装置、湿式除尘洗气机 |
| 未分类项目 | 兜底 |

### 3. 为什么这样合并

- 各风机（轴流/屋顶/防腐防爆）同属通风功能 → 合并；
- 除尘抑尘各装置同属粉尘治理功能 → 合并。

### 4. 为什么这样拆分

- 供暖与空调制冷功能不同 → 拆分；
- 通风风机与除尘抑尘功能不同 → 拆分。

### 5. 命名特点

按功能命名：供暖设备、空调设备、通风风机设备、除尘抑尘设备。

### 6. 常见错误

- 把风机、空调塞进「工控服务器 UPS」或「机柜箱体配电」；
- 不区分通风与除尘功能而全部塞进一个类。

## 使用说明

1. 分类前**必须读取**本文件（见 SKILL.md「动态分类方法论」）；不能只根据 SKILL.md 描述假装参考了案例。
2. 智能化/弱电、暖通/动力、供配电、选煤厂项目优先查找对应案例。
3. 复合工程（同时含供配电 + 智能化 + 暖通等）应读取多个相关案例，分别学习各专业分类形态，再统一形成当前工程目录；不得强行把整个工程识别成单一类型。
4. 案例库中没有直接对应类型时，按 SKILL.md 动态分类方法论自行生成分类，并明确说明"无直接案例，按当前工程动态分类"。
5. 出现新的真实工程人工分类结果时，优先整理成新案例追加到本文件，而不是往 SKILL.md 增加固定设备关键词规则。
